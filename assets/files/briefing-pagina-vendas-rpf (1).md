## 2. Sistema de design (o mesmo do Guia de Clareza e do quiz — manter consistência de marca)

### Paleta

| Uso | Hex |
|---|---|
| Fundo da página (off-white/creme) | `#F8F2E7` |
| Fundo de cards/seções alternadas | `#EFE4D2` |
| Texto principal (marrom escuro — nunca preto) | `#3C2A1E` |
| Texto secundário | `#6B5847` |
| Acento quente (terracota) | `#B85C2E` |
| Bloco escuro (CTA, preço) | `#3C2A1E` |
| Texto sobre bloco escuro | `#F8F2E7` |
| Fios/divisores | `#D8C8AE` |

### Tipografia

- **Títulos:** serifada elegante e delicada (Cormorant Garamond, Playfair Display ou EB Garamond), peso regular/semibold — nunca bold pesado.
- **Corpo:** sans-serif leve (Inter, Lato ou Nunito Sans), ~16px no desktop / ~15px no mobile, entrelinha ampla (~1,6).
- **Rótulos/eyebrows** (ex.: "MÉTODO R.P.F."): caixa alta, pequeno, espaçamento entre letras, marrom suave ou terracota.
- Nada de preto puro em nenhum texto. Nada de emoji — usar ornamentos vetoriais simples (linha fina, losango, ponto) em terracota.

### Sensação geral

Clean, delicado, muito respiro entre seções, cantos arredondados suaves (12–16px), sem sombras pesadas, sem gradiente, sem elementos piscando ou "urgência" gritada. Uma página de vendas que parece uma carta pessoal bem cuidada, não um funil agressivo.
