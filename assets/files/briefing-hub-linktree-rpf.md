## 2. Sistema de design (igual às outras peças — manter consistência de marca)

| Uso | Hex |
|---|---|
| Fundo da página (off-white/creme) | `#F8F2E7` |
| Fundo dos botões | `#FFFFFF` ou `#EFE4D2` |
| Texto principal (marrom escuro — nunca preto) | `#3C2A1E` |
| Texto secundário | `#6B5847` |
| Acento quente (terracota) | `#B85C2E` |
| Fios/divisores | `#D8C8AE` |

- Título/nome: serifada elegante (Cormorant Garamond, Playfair Display ou EB Garamond)
- Corpo/botões: sans-serif leve (Inter, Lato ou Nunito Sans)
- Sem emoji nos textos — usar ornamento vetorial simples (ponto, linha fina) em terracota, se quiser um ícone ao lado de cada botão
- Cantos arredondados (12–16px), muito respiro, nada apertado
